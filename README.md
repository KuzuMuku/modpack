# 整合包说明

这是一个以维度探索为主线的整合包。玩家会从主世界出发，逐步前往下界、暮色森林、天境、幽冥异界和末地，在探索过程中按自己的喜好选择 `探索+魔法流` 或 `科技+宅家流`，通过器官、装备、魔法和工业体系不断强化自己。

任务书会优先引导新人站稳主世界，再逐步开放各条支线，避免一开始就面对过多模组信息。
